# sql-data-analytics-project

This repository is a curated collection of SQL scripts designed for data exploration, analytics, and reporting. It serves as a practical reference for data analysts and BI professionals who want to quickly extract insights from relational databases.

The scripts cover a wide range of analytical use cases, including:

o	Database exploration & profiling
o	Key measures and business metrics
o	Time-based analysis and trend tracking
o	Cumulative and rolling calculations
o	Customer and prduct data segmentation
o	Performance and comparative analysis


Each SQL file focuses on a specific analytical theme and demonstrates clean, efficient SQL practices that are commonly used in real-world analytics and reporting scenarios.
